# Legacy Selenium scaffold

Giữ lại khung Selenium trước QA-28 để tham khảo. Một số file có JSON escape sai, template string thiếu backtick hoặc import sai; chưa xác minh các luồng trong thư mục này. Runner dùng chung tại `../run.js` không import legacy.

Khi cần test Giáo viên/Học viên/Admin, chuyển hành vi cần thiết sang Page Object và case của framework hiện hành, kiểm tra trên dữ liệu QA trước khi dùng. Không coi placeholder cũ là coverage đã thực thi.
