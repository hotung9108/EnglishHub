# Điều hướng theo UC

Code đã chia theo cùng nhóm chức năng và UC trên Qase. Xem [mục lục source](../../cases/README.md), [chỉ mục 170 ca](../../catalog/case-index.csv) và `uc-layout.json` để tra ID suite.

168 procedure, 2 ca ngoài phạm vi; ID Qase giữ nguyên. Đây là sắp xếp thư mục, chưa duyệt chất lượng nội dung case. Lượt đọc lại toàn bộ Qase sau chuyển UC trước đó chưa hoàn tất do phản hồi chậm.
